# Acme Mobile App

## Supported platforms

The Acme app requires iOS 16 or later, or Android 12 or later. Older devices can still
use the mobile website, which supports order tracking and returns but not push
notifications.

## Features

The app supports order tracking using the same ACM-XXXXXXX code shown on the shipping
confirmation email, push notifications for delivery updates, and a barcode scanner for
starting a warranty claim from a product's serial number.

## Offline mode

Previously loaded order and tracking data remains viewable offline, but tracking
statuses only refresh when the device has an internet connection. The app does not
support placing new orders while offline.

## Notifications

Push notifications for delivery updates can be disabled in the app's settings without
disabling account or security notifications, which are always sent by email regardless
of the app's notification settings.
